# 만칼라 🫘

컴퓨터와 하거나 방 코드로 친구와 실시간 대결하는 만칼라(2인, **칼라 규칙**). [작은 오락실](https://github.com/hye-rim/smallgame)의 게임 중 하나. `public/`(`index.html` + `logic.js` + `game.js`)과 온라인 대전용 `server.js`(`ws`)로 이루어져 있습니다.

- **판**: 구덩이 6개씩 2줄과 양 끝의 창고 2개. 구덩이마다 콩 4개(전체 48개). 내 줄은 아래, 내 창고는 오른쪽
- **두기**: 내 구덩이 하나의 콩을 모두 집어 **한 칸에 하나씩 오른쪽(시계 반대 방향)으로** 뿌린다. 내 창고에는 넣고 **상대 창고는 건너뛴다**. 콩이 많으면 판을 한 바퀴 돌 수도 있다
- **한 번 더**: 마지막 콩이 **내 창고**에 떨어지면 한 번 더 둔다 (이어서 계속될 수 있다)
- **가져오기**: 마지막 콩이 **내 쪽의 빈 구덩이**에 떨어지고 맞은편 구덩이에 콩이 있으면, 맞은편 콩과 방금 떨어진 내 콩 1개를 내 창고로 가져온다 (맞은편이 비었으면 그냥 둔다. 상대 쪽 빈 구덩이에서는 안 가져온다)
- **끝**: 한쪽 줄의 구덩이가 모두 비면 끝나고, 남은 콩은 그 줄 주인의 창고로 간다. 창고 콩이 더 많은 쪽이 이기고 같으면 무승부. 창고에 **25개 이상**(과반) 모으면 그 자리에서 이긴다. 한 판이 400수를 넘으면 안전장치로 창고 수로 가른다
- **컴퓨터**: 쉬움은 한 수 앞만 보고 창고에 가장 많이 넣는 수(한 번 더는 덤)를 고르되 35% 는 아무 구덩이나 고른다. 어려움은 **8수 앞을 내다보는 알파-베타 탐색**(창고 차이 x10 + 내 줄과 상대 줄의 콩 차이)이고 **다섯 번에 한 번쯤(`HARD_SLIP`)은 쉬움처럼 둔다**. 한 번 더 두는 수와 가져오는 수를 먼저 살펴 가지치기를 돕는다. 컴퓨터 대전은 "다시 하기"마다 먼저·나중이 바뀐다 (이 규칙은 먼저 두는 쪽이 유리하다)
- **온라인 대전**: 빠른 대전 · 4글자 방 코드(초대 링크 `?room=코드`) · 재접속(30초) · 한 번 둘 때마다 45초(넘기면 시간패, 기권·이탈도 패배) · 한 판 더(먼저·나중 교대). 모든 동작은 `act` 하나(`{type:'sow', pit}`)로 오고 서버가 같은 규칙(`public/logic.js`)으로 검사한다. 지금 둘 수 있는 구덩이(`legal`)는 차례인 쪽에만 보낸다
- 화면: 둘 수 있는 구덩이는 노랗게 빛나고, 콩이 한 칸씩 떨어지는 모습을 보여 준다. 한 번 더·가져오기는 큰 글씨와 구덩이 깜빡임으로 알린다
- 컴퓨터를 이긴 횟수는 `mancalaWins` (로비 표시용), 온라인 전적은 `mancalaOnline`

규칙·컴퓨터는 `public/logic.js`(화면 없이 Node 로 시험), 화면·입력·소리·온라인은 `public/game.js`, 방·매칭은 `server.js`. 시험은 `npm test`(= `node --test`): `test/logic.test.js`(처음 판, 뿌리기, 한 번 더, 상대 창고 건너뛰기(양쪽), 가져오기와 안 되는 경우, 한 바퀴 도는 13개, 끝내기·무승부·과반, 잘못된 동작, 무작위 120판에서 콩 48개 보존, 컴퓨터가 한 번 더·가져오기를 고름, 어려움이 쉬움을 이김), `test/server.test.js`(서버를 띄워 매칭 · 차례인 쪽에만 둘 구덩이 · 입력 검사 · 두 화면 동기화 · 한 번 더 · 빈 구덩이 거절 · 무작위로 끝까지 · 기권 · 한 판 더 · 시간 초과 · 재접속).
